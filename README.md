# CloudCode Ollama Setup

Eigenständiges Windows-Setup für [DocumentAI](https://github.com/AOWDGENESIS/documentai)
und lokale Coding-Agenten mit Ollama. Die ausführliche Anleitung steht in
[`ANLEITUNG.md`](ANLEITUNG.md).

Das Paket ist unabhängig vom DocumentAI-Quellcode und kann als eigenes
Repository veröffentlicht oder direkt als ZIP verteilt werden.
